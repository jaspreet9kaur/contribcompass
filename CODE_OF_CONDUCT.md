# Community conduct

Treat people respectfully. Critique ideas and code rather than people. Harassment, threats, discriminatory remarks, unwanted contact, and publishing private information are unacceptable.

Maintainers may edit or remove abusive material, pause a discussion, or restrict participation. They should explain moderation decisions where doing so does not reveal private information.

Before this project opens to public participation, the maintainer must establish a private reporting route and an alternate contact for complaints involving the maintainer. Those contacts are not configured in this local prototype. Public issues are not a suitable place for confidential reports. This limitation must be resolved before community launch.
